# Competitor watch (2026-09-22)

None of these does our exact thing (continuous auto-journey + roamable real-time
3D + deterministic epic canon + open pipeline). Learn from each instead.

| Competitor | What they do | Our learning |
|---|---|---|
| OUTERBOOK (outerbook.ai) | AI living story worlds, talk-to-characters, canon preservation | Character-consistency engine idea; we answer with embodied cast, not chat |
| 3DStoryteller Studio | **Unity-based** creator studio (docs teach Unity custom-asset import), native apps + web beta | Closest on 3D. Learn: visual branching editor, text-to-voice, prop gen. WE DIFFER: open web-Three.js pipeline, no engine lock-in |
| Narratica | Text-RPG world bible as source of truth, community scenarios | Validates our story-bible-first design; we add real 3D + journey |
| StoryRift | Dynamic NPCs, persistent memory, XR-ready | Persistent memory across visits = our future save/continue feature |
| NUMUSE | One canon → trailer/audiobook/storybook/VR outputs | We already emit keyframes+WAVs: storybook/audiobook variants are cheap |
| Storys.ai | Visual novels + 2D/3D experiences, AI character gen | Waitlist-stage; no moat beyond tooling |

## Our moat (keep sharpening)
1. Roamable real-time 3D worlds, not chat bubbles or visual novels.
2. Infinite-zoom-style continuous journey with user pacing (nobody does this).
3. Deterministic reproducible pipeline (Blender scripts + seeds), not genAI soup.
4. Epic-canon focus (Mahabharata first) + open-source repo.
